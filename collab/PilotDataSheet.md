## A. Signed at intake (before any work)

1. **Reference permission** — client agrees to be a named reference and to a short testimonial on completion. Signed: ☐ date: ___
2. **Next-project price** — client agrees in writing: *"My next project with UrbanOS is at ₹ ______ for [scope]."* Signed: ☐ date: ___
   - This is the only willingness-to-pay data that involves a signature. A pilot without this signature is a favor, not a pilot.
3. Waived invoice issued — invoice # ___, list price shown ₹ ______, waived 100%. ☐

## B. The counterfactual — captured at intake

4. **The real quote.** Attach the actual quotation (paper/PDF/WhatsApp) from the consultant/liaison they would have used *for this plot*. Not recalled numbers — the document.
   - Attached: ☐  Amount: ₹ ______  Scope described in quote: ______
   - If no quote exists, record who they *would* have called and get the number from that person if at all possible.
5. **The real timeline, from their last comparable project** (dates, not estimates):
   - Land purchase: ___ → feasibility answered: ___ → drawings ready: ___ → file submitted: ___
   - Weeks land sat idle waiting on feasibility: ___
6. **Fee breakdown** (with Mannu): of the end-to-end consultant fee, what fraction is the front-end UrbanOS displaces (research / feasibility / test fit) vs. what remains (signed drawings, approvals liaison)? ______ %
7. **Plot economics** (for the carrying-cost anchor):
   - Plot purchase price: ₹ ______
   - Financing: own funds ___ % / borrowed ___ % at ___ % interest
   - Their stated cost of one idle month on this plot: ₹ ______
8. **Frequency check** (tests the [inferred] quarterly claim): projects done in the last 24 months: ___ ; next plot purchase expected: ______

## Standing triggers (from Money v1 — restated here so the sheet enforces them)

- The moment **any** pilot requests a second project → that project is **paid at their signed §A price**, regardless of pilot count.
- **Any referral** arrives → paid at list from day one. Free was for strangers; there are no free friends-of-pilots.
- Pilots 1–2: fully waived. Pilots 3–5: waived + signed next-project price mandatory (§A.2).

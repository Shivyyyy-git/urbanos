## One sentence

Per-project pricing for the evidence package, subscription pricing for the rulebook — anchored on weeks saved and rule certainty at rough parity with the displaced consultant scope, never discounted, never approval-priced.

Not launched until a base of clients has verdicts on file **[proposed — sequencing]**; data model built for it from day one. ₹ ______ / plot / year **[Mannu]**

## Anchors **[inferred — needs Mannu's numbers]**

- **Floor: the displaced consultant scope.** UrbanOS replaces only the front-end (research, feasibility, test fit) — someone still signs drawings and walks approvals ("Ready for Professional Review" **[locked]**). We can claim only that fraction. End-to-end liaison fee ₹ ______, front-end fraction ___ % **[Mannu]**.
- **Real anchor: the weeks.** Carrying cost of a ₹3–8 cr plot idle 4–6 weeks (financing interest or the next deal foregone), plus the tail risk of building against a rule that changed. Sell velocity and certainty, not discount. Per-pilot carrying costs from PilotDataSheet §B.7.
- **Ceiling: approval-adjacency.** Price must stay clearly below what statutory-approval work costs, or clients will read the document as approval no matter the stamp — the price has to cooperate with the never-say-approved rule **[locked]**.
- **Posture: parity, not discount [proposed — Shivam leans yes, 2026-08-16].** Same money as the displaced scope, days instead of weeks, every rule cited. Discounting signals doubt in a trust market.

## Pilot economics **[proposed — Shivam leans yes, 2026-08-16]**

- Pilots are **unpaid, never free**: real invoice, list price shown, 100% waived, "Pilot Partner Program."
- Pilots 1–2 fully waived; pilots 3–5 waived **plus** signed next-project price at intake (PilotDataSheet §A).
- Five signed next-project prices = the demand curve the premium price is set from.
